# T7 Studio

A cinematic toolkit for Call of Duty: Black Ops III theater, running inside the game under the BOIII client.

> **Beta.** Expect rough edges. Offline use only: T7 Studio refuses any client other than the supported BOIII build.

## Download

Get the latest `T7Studio-<version>.zip` from [Releases](../../releases/latest).

## Requirements

- Black Ops III on Steam
- The supported `BlackOps3.exe` build (T7 Studio guides you through the Steam depot download and keeps a backup of yours)
- The supported BOIII client (T7 Studio can download it for you)

## Install

1. Unzip anywhere.
2. Run `T7Studio.exe`. Its setup screen checks everything above and fixes what it can.
3. Press PLAY. T7 Studio starts the game and attaches itself.

Plugin updates arrive through the launcher automatically. When a new `T7Studio.exe` is needed, the launcher sends you here.
