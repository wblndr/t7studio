# T7 Studio

Cinematic toolkit for Black Ops III theater, running inside the game under the BOIII client. Press **Tab** in a demo for the editor overlay.

> **Beta.** Offline use only, on your own install.

## Features

- **Camera:** real lens units (mm, f-stop, focus), lens-driven depth of field, exposure, free cam out of bounds
- **Bone cam:** lock the camera to any bone of any player
- **Dolly:** camera keys on a timeline, lens lanes, clean frames while a shot plays
- **Look:** fog, sun, haze, colour grade, thermal / IR, saved per map
- **Death animations:** swap any player's death anim
- **Demos:** fast seek, slow motion, kills timeline
- **Projects:** save everything as one `.t7s` file, open it from the main menu

## Install

1. Download `T7Studio-<version>.zip` from [Releases](../../releases/latest) and unzip it.
2. Run `T7Studio.exe`. It checks Black Ops III (Steam), the supported game build and the BOIII client, and fixes what it can.
3. Press **PLAY**.

Updates come through the launcher.
